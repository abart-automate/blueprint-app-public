PWA Icon Generator

Opens icons/icon-source.svg and exports all required PNG sizes. Save each file into the icons/ folder.

How to use: Serve this file with a local server (e.g. npx serve . or VS Code Live Server), then open it in Chrome. Icons will generate automatically. Click each download link and move the file to icons/. You cannot open this via file:// due to CORS restrictions on SVG loading.
